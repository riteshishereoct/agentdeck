Claude Code, within reach

Your agents. Your decisions.

A native Mac overlay for Claude Code sessions. Codex and other agents are not tracked.

Run five agents. Stay in flow.

You started Claude Code in three projects. One is waiting for a yes. One asked a question ten minutes ago. One finished and nobody noticed. AgentDeck is the floating deck that keeps every session in view, wherever you are working.

What

A native Mac overlay listing every Claude Code session across your Cursor windows and terminals: what each is doing now, what it is waiting for, and what it last finished.

Why

Agents stall silently on a permission prompt or a question. Every stall is parallel work not happening. AgentDeck shows the stall the moment it starts, so five sessions keep moving instead of you babysitting one tab.

How

Claude Code hooks report each step to the app on your Mac over a local connection. With tested controls on, you allow, deny with a note, or answer a question from the card, and the session carries on.

Agent asks→Deck lights up→You decide→Agent continues

Built for developers who multitask

  • One glance. The pill reads like a team standup: who is working, who needs you.
  • Decide without switching. Answer on the card, or jump straight to the exact session tab in Cursor.
  • Safe by design. Actions arm only after the full request is visible; risky commands need a deliberate hold; silence never approves.
  • Out of the way. Click-to-open pill, hides when idle, near-zero CPU while you work.
  • Local by default. No account and no cloud service. The optional summarizer stays off unless you enable it.
Made for the developer running a refactor in one session, tests in another and docs in a third, who wants to lead agents like a team, not chase tabs.

Start here.

Apple silicon. macOS 14+. Working system Python 3.

  1. Unzip the shared release. Read its README, then open Install AgentDeck.command in Finder.
  2. Open AgentDeck. Choose Setup & Help… from its menu bar or Settings. Install or repair hooks works before any session exists.
  3. Start a fresh Claude Code session in Cursor. Check its source and current step. Keep the host available.
Installation defaults to notifications only. Opening the app alone does not install hooks.
Optional controls and release helpers

Verify your active Cursor Claude Code extension is exactly 2.1.325 before using Enable tested controls.command. Test harmless allow, deny and question flows. Run Reset to notifications.command before extension updates. There is no runtime version guard or automatic downgrade. Uninstall AgentDeck.command removes the integration. These helpers are alongside the app in the shared ZIP.

Known gap: memory target not met. Target is peak RSS of 60 MiB or less at idle; this build peaked at 97.2 MiB after typing an answer. Cause found: macOS text-input frameworks. A bare SwiftUI app with one text field already peaks near 88 MiB RSS. No app leak was found.
Release evidence and limits

Packaged build: 467 tests passed; ten-minute idle CPU 0.057% of a core, peak RSS 97.2 MiB (FAIL against 60 MiB). See the README. Snyk Code found zero Sources findings; secrets scanning was unavailable. Intel, physical display hot-plug, visual notification banners and mobile push are unverified. This ad-hoc signed pilot is not notarized.

Stay oriented.

Open and move

Click the pill; hover opening starts off. Enable Open on hover in Deck controls or Settings. New requests stay minimized in click mode.

Drag the pill or header. Resize with bottom-corner grips. Scroll requests and sessions separately. Use menu-bar Show if hidden.

Read the session

Check project, goal, short ID and source. Now is reported running; Waiting needs a decision; Last is past activity. Silence does not prove completion or available quota.

Privacy hides sensitive overlay content and cards. Sounds can be disabled; Quiet suppresses attention and cards. Pause disables Deck supervision, not Claude. The optional summarizer sends assistant text through Claude/Haiku over the network; it starts off.

Review before deciding.

  1. Verify identity, requested action, scope and full details. The agent’s explanation is labelled separately.
  2. Scroll to the end. Keep the complete card visible and still for about 600 ms. Moving, resizing or hiding disarms actions.
  3. Allow a supported request, deny it, or add a denial note. Supported questions accept choices and Other text. Opening the host never approves anything.
Hold for one second when required: high risk, long/incomplete details or broad permission rules. Releasing early cancels. Native VoiceOver offers two activations.

Controls depend on the optional tested profile and capability channel. Host-only approvals and plan reviews stay in Cursor. Arbitrary follow-ups are prefill only; send them in the host. A notice is not a universal tool gate.

Grant only what you need.

macOS blocks opening

Verify the sender and organization policy. For a trusted copy, open in Finder and review Privacy & Security → Open Anyway if offered. You approve the OS prompt.

Python or protected-folder access fails

Complete approved system Python/developer-tools setup, then retry hook installation. For denied Documents access, review the named app in Privacy & Security → Files & Folders. Retry or reopen it. Ask your administrator if blocked; broad disk access is not a routine requirement.

Cursor asks to trust a folder

Review each workspace before trusting it. One user-level Claude hook installation serves multiple project folders on this Mac. It does not trust all folders, approve future tools or add support for other agents.

Privacy is display masking, not encryption or deletion. Local hook/transcript data still exists.

Find the next step.

Empty deck?

Choose Show, install hooks globally, then start a fresh Claude session.

Actions disabled?

Disable Privacy/Quiet, enlarge the panel, scroll fully, and wait 600 ms.

Hooks degraded?

Check connection, then explicitly repair hooks. Reconnecting is not recovery; a fresh same-session hook confirms recovery. Restart the Claude tab if instructed.

No approval card?

Default mode is notifications only. Host, presence, permissions, Claude mode and capabilities affect gating.

No sound or banner?

Check Sounds, Quiet, Privacy and macOS notification settings.

Request disappeared?

It may be resolved, expired or handled elsewhere. Read the current host state.
